# RadioAI

Проект для анализа радиосигналов с использованием машинного обучения и моделирования виртуальной радиосвязи.

## Возможности

- Генерация и визуализация радиосигналов.
- Анализ и распознавание сигналов с помощью обученной модели.
- Виртуальная радиосвязь между двумя радиостанциями.
- Шифрование сообщений, включая AES-128-GCM.
- Тестирование передачи сообщений и обработки ошибок.

## Требования

- Windows 10 или Windows 11.
- Python 3.11 или 3.12.
- Git.

## Установка

Открой PowerShell и выполни команды:

```powershell
git clone https://github.com/TwiceDiceIce/RadioAI.git
cd RadioAI
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если PowerShell запрещает активацию виртуального окружения, можно запускать Python напрямую через `.\.venv\Scripts\python.exe`, не меняя политику безопасности.

## Запуск

Из корневой папки `RadioAI` выполни:

```powershell
python -m streamlit run app/main.py
```

После запуска Streamlit покажет локальный адрес приложения в терминале. Обычно это:

http://localhost:8501

Открой этот адрес в браузере.

## Структура проекта

- `app/` — интерфейс приложения.
- `src/` — обработка сигналов, модель и виртуальная радиосвязь.
- `data/` — данные для работы с сигналами.
- `models/` — обученная модель.
- `tests/` — тесты проекта.

## Примечание

Команды запуска следует выполнять из корневой папки проекта, где находится `requirements.txt`.
